# Progress notes — Red Lines (Middle East 2026 matrix game)

_Last updated: 2026-10-11 (session 1)._

## What exists
A playable browser prototype. No build step: plain ES modules served statically.

```
npm install          # dev deps only (map baking + Playwright)
npm run serve        # http://localhost:8080  (or: node tests/server.mjs 8080)
npm test             # engine checks (Node) + browser checks (Playwright/Chromium)
node tests/sim.mjs 20 1 --goals   # AI-vs-AI balance sweep (per-goal progress)
node tests/verdicts.mjs 3         # AI plays each seat: victory/draw/defeat counts
node tests/peek.mjs '/?play=iran&dev=1' out.png   # one-off capture into test-output/
```

### Layout
- `src/data/` — scenario content: `actors.js` (19 playable actors, goals, relations), `theaters.js` (22 map hotspots, adjacency, starting influence), `world.js` (global tracks), `events.js` (random, scripted, threshold events), `map.js` (GENERATED by `tools/build-map.mjs` from Natural Earth 50m via world-atlas).
- `src/engine/` — pure, DOM-free, runs in Node: `state.js` (plain-JSON state + mutation helpers), `actions.js` (31 actions: cost, base odds, situational modifiers, effects), `adjudicate.js` (probability + d100), `ai.js` (one-ply expected-utility AI + debate), `game.js` (turn phases, upkeep, events, victory), `goals.js`, `rng.js` (seeded mulberry32 stored in state).
- `src/ui/` — `mapView.js` (SVG map, Levant inset, arcs, cameras), `panels.js` (HTML renderers). `src/main.js` controller. `src/dev/dev.js` hooks.
- `tests/` — `engine.mjs`, `browser.mjs`, `run.mjs`, `sim.mjs`, `verdicts.mjs`, `server.mjs`, `peek.mjs`.

### Game loop (matrix game)
Turn = 2 weeks from 12 Oct 2026, 16 turns. Each turn:
1. **Declare** — player picks action, target (list or click on map), commitment (Standard / Major +8% / All-in +15% at 1.5×/2× cost). The GM shows the base likelihood and every situational reason for/against.
2. **Debate** — all AI actors declare (expected-utility lookahead). Actors whose utility moves ≥1 point spend political capital to argue (±3–7% each, capped ±25%). The player sees declarations that touch their goals and may Support/Oppose (1 PC).
3. **Adjudicate** — random initiative order; d100 ≤ p succeeds, bottom fifth of the band is decisive (×1.5 effects), 96+ on a failure is blowback. Then upkeep (income, chokepoint caps, drift, oil price), events, collapse checks.

Victory at turn 16: score ≥ max(60, start+15) **and** at least half of objectives fully met. Draw if score ≥ start−5. All objectives met (turn ≥3) = decisive early win. Stability 0 = collapse = defeat.

URL params: `seed`, `play=<actorId|observer>`, `auto=1`, `autodt=<ms>`, `cam=<name>`.
Diagnostics overlay (dev only): frame ms, last turn-compute ms, DOM/SVG node counts, GPU string, seed/turn/phase/cam, last error.
Not applicable to this 2D turn-based game and stubbed/omitted: `setTimeOfDay` (returns false; use `setTurn`), draw calls / shader-program count (SVG, reported null), fixed-timestep `simdt` (sim is discrete turns; `autodt` paces autoplay).

## Known issues / next
1. **Balance**: status-quo actors (Hamas, PIJ, Iraqi militias) win too easily; SDF almost always collapses; most actors' scores rise in AI-vs-AI (world drifts toward Hormuz reopening). Tune goal baselines and AI aggression, and consider score relative to an AI-baseline run.
2. AI is one-ply and myopic (e.g. withdraws escorts it needs). Add 2-ply or scripted doctrines per actor.
3. Free-text arguments: the matrix-game ideal is players writing arguments. Option: optional LLM game master that reads the player's argument and proposes modifiers (needs an API key/proxy — design decision for the user).
4. Hidden information: all declarations are public in debate; consider secret actions (covert ops revealed only on resolution).
5. More armed groups as playable/NPC: Kata'ib Hezbollah split from the IRI umbrella, PKK remnants, PJAK/Iranian Kurdish parties, Jaish al-Adl, AQAP, Druze militias of Sweida, Popular Mobilization Forces as a state actor; Gulf states (UAE, Qatar, Oman), Jordan, Pakistan.
6. Save/load (state is plain JSON — trivial to add to localStorage).
7. Multiplayer hot-seat (engine already supports per-actor declarations).
