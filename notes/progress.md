# Progress notes — Red Lines (Middle East 2026)

_Last updated: 2026-10-11 (session 2)._

## What exists
A playable browser prototype. No build step: plain ES modules served statically.

```
npm install          # dev deps only (map baking + Playwright)
npm run serve        # http://localhost:8080  (or: node tests/server.mjs 8080)
npm test             # engine checks + situation content probe + browser checks (Playwright/Chromium)
node tests/sim.mjs 20 1 --goals     # AI-vs-AI balance sweep (per-goal progress)
node tests/verdicts.mjs 3           # AI plays each seat: W/D/L per seed
node tests/situations.mjs 2         # cards dealt per turn, never-fired situations, content errors
node tests/peek.mjs '/?play=iran&dev=1' out.png ["js to run first"]   # one-off capture
```

### Layout
- `src/data/` — scenario content: `actors.js` (19 playable actors, goals, relations), `theaters.js` (22 map hotspots), `world.js` (global tracks), `events.js` (random, scripted, threshold events), `map.js` (GENERATED by `tools/build-map.mjs`), `situations/` (the card deck: `dsl.js` helpers, `generic.js`, `powers.js`, `states.js`, `groups.js`, `index.js`).
- `src/engine/` — pure, DOM-free, runs in Node: `state.js`, `actions.js` (catalogue), `adjudicate.js` (odds + hidden roll), `ai.js` (one-ply expected-utility AI, grudges, truce/restraint flags, gang-up-on-the-leader), `director.js` (deals cards, ranks proposals, resolves choices, compiles the briefing), `game.js` (turn flow, upkeep, events, victory), `goals.js`, `rng.js`.
- `src/ui/` — `mapView.js`, `panels.js`. `src/main.js` controller. `src/dev/dev.js` hooks.
- `tests/` — `engine.mjs`, `situations.mjs`, `browser.mjs`, `run.mjs`, `sim.mjs`, `verdicts.mjs`, `server.mjs`, `peek.mjs`.

### Game loop (session 2 redesign)
Turn = 2 weeks from 12 Oct 2026, 16 turns. One screen per turn:
1. **Situations.** The director deals up to two cards (a crisis and an opportunity, chosen by priority from everything whose `when` is true, honouring cooldowns/`once`) plus an intelligence card on the one AI declaration that matters most to you. Each card has 2–4 options with cost, worded odds ("Likely"), and a fold-out of the reasons. Unanswered cards take their default (always a free option).
2. **Initiative.** One catalogue move. Advisers propose the top five by expected gain (housekeeping moves excluded), with the objective each one advances; the full catalogue is behind a toggle. The preview includes the lobbying the move is expected to meet.
3. **End turn.** Card responses resolve first, then every declaration in random order (AI actors declared before the player moved). Rolls are hidden; outcomes are narrated. Upkeep, events, collapse checks. A briefing overlay shows: your decisions with their measured impact on your tracks, AI moves and events that moved your position (relevance = goal-score delta, resource delta, or touching you/your theaters), and everything else folded away.

Chains: results go into `s.recent` (last 4 turns) and flags; situations read them (`h.did`, `h.hit`, `h.event`, `h.chose`, `h.flag`). Options built from catalogue actions are also recorded as actions, so the AI's grudges and the chains see them (bomb Iran → "Iran answers in the Gulf" + "Jerusalem asks for the big bombs" next turn).

Victory: score ≥ max(68, start+22) **and** ≥ half of objectives fully met at turn 16; draw if ≥ start−5; all objectives met after turn 6 = decisive early win; stability 0 = collapse.

## Verified (session 2)
- `node tests/engine.mjs`: content probes, scripted player turn through the API (cards dealt, choose, initiative, endTurn, briefing split, recent history), 3 observer games with no NaN, same-seed determinism.
- `node tests/situations.mjs 2`: 148 situations, 0 content errors; cards per turn 1.3–2.0 for every seat; AI-played seats see 9–16 distinct situations per 2 games. 26–32 situations never fire in AI-only games — most are chain-dependent (they need the player to have done the thing).
- `node tests/browser.mjs`: cold boot clean; real-mouse path (pick US → answer the CENTCOM card → pick a proposal → open the catalogue → choose air strikes → click Hormuz on the map → raise commitment → end turn → briefing overlay → continue) with getState assertions; no digits in the odds display and no "d100/roll" text in the briefing; stills over all 19 actors (each with ≥1 card) and 5 cameras; 10 s autoplay soak completes 16 turns; phone viewport has no overflow.
- Balance (AI plays each seat, 3 seeds, after this session's tuning at floor 70/gain 25): 9 W / 46 D / 2 L with final scores mostly 65–85. Thresholds then lowered to 68/22 and half-of-objectives (not re-swept).
- Perf: turn compute ~100–250 ms in headless Chromium (proposals + 19 AI lookaheads + card generation).
